# img2stl

> A C++ based utility to convert a png-image to an stl-file
>
## usage
> After compiling or downloading the img2stl binary the following syntax is required:
> 
> ```img2stl /path/to/image.png /path/to/stl.stl```
>
> This will generate the specified stl as well as a png that represents the look of the stl (named /path/to/imagebw.png)
>
